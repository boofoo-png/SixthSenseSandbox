# /sync — Preflight check

Read-only. Do not commit, pull, merge, rebase, stash, or discard anything. Report only.

## Steps

1. **Fetch remote state**
   ```bash
   git fetch --prune
   ```
   If there is no remote (`git remote` is empty) or the fetch fails (offline, auth), note it in the summary and continue with local checks.

2. **Check branch health**
   - Current branch: `git branch --show-current`. If empty, the repo is in detached HEAD — flag it.
   - In-progress operations: check whether `.git/MERGE_HEAD`, `.git/rebase-merge`, `.git/rebase-apply`, `.git/CHERRY_PICK_HEAD`, or `.git/BISECT_LOG` exist. Flag any that do.
   - Upstream: `git rev-parse --abbrev-ref --symbolic-full-name @{u}`. If none is set, flag "no upstream tracking branch".
   - Upstream gone: if `git status -sb` shows `[gone]`, flag that the remote branch was deleted (likely already merged — suggest `/landed`).

3. **Ahead/behind counts** (only if an upstream exists)
   ```bash
   git rev-list --left-right --count @{u}...HEAD
   ```
   The first number is **behind**, the second is **ahead**.
   - Behind > 0: recommend `git pull --rebase` (do not run it).
   - Ahead and behind both > 0: flag as **diverged**.

4. **Dirty files**
   ```bash
   git status --porcelain=v1
   ```
   Group the output into: staged, modified (unstaged), untracked, and conflicted (`UU`, `AA`, `DD`, etc.).
   Ignore files only regenerated by tooling if they are in `.gitignore` (they won't appear anyway).

5. **Report** a short summary in this shape:

   ```
   Branch:   feature/x → origin/feature/x
   Status:   ✅ up to date   (or: ⬆ 2 ahead, ⬇ 3 behind, ⚠ diverged, ⚠ no upstream)
   Dirty:    3 files
     M  app/page.tsx
     ?? app/new-thing.tsx
     A  docs/DECISIONS.md
   Warnings: (any detached HEAD / in-progress rebase / gone upstream / fetch failure)
   Next:     one-line suggested action, if any
   ```

   If everything is clean and current, say so in one line.
